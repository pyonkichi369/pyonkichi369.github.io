優先順位プロトコル#

問題: 複数のタスクが全部「同じ重さ」に見えて、何から始めるか決められない。

毎朝3分でAIにプロジェクトをスコア化させ、1つのタスクだけに集中する仕組み。ADHD脳の「判断疲れ」を根本から解消。

タスク開始プロトコル#

問題: 優先順位はわかっているのに、体が動かない「開始の地獄」。

大きなタスクを「25分で完結できるサイズ」に砕き、「開始トリガー」を設定する。実行機能障害を構造で回避する方法。
